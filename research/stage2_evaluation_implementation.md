# 第二阶段测试的执行约定

以下约定在新测试首次生成前写入；不修改冻结的 stage2-v1.1 研究问题、模型或统计端点。

- 三种噪声家族按协议列出顺序使用 seed `902000 + 1000 × family_index`。同一家族的10种脉冲共享无冲击路径，因此网格结果互相关联；不把30种情景当成30个独立复现。
- 每次预测仅输入 `y[t-L:t]`，GRU状态每个目标重新初始化。最初缺失的历史左补零；评分从第384步开始，此时这些零已被有限上下文忘记。滚动归档另用验证路径0最后128个已发出标准化分数热启动。
- 为减少计算，无冲击模型尺度先计算一次。事件尺度只重算 `[onset+1, exit+L)`，这是上下文可能含有事件观测的精确目标集合；其余上下文和模型权重完全相同。事件标签只用于生成、评分和缓存调度，不传给模型或校准器。
- 每个模型、情景独立重算 onset 与 `exit+L` 的边界目标，核对缓存。另有独立于真实测试的小型全轨迹未来干预、局部/全轨迹预测一致性、逐点标量滚动分位数核对。退出192步后的有限记忆负控制包含30情景的全部神经模型/窗口。
- 所有情景保存按模型种子与方法的两世界平均表现，以及逐配对路径的事件减无事件 context×window 交互量。主端点使用该交互的 GRU 减 TCN；负数表示 GRU 的交互项更低，不等于 GRU 的区间总评分必然更低。
- 样本覆盖率用已实现结果是否落入区间；coverage deficit 用模拟分布的 oracle 概率，逐点计算 `max(.9-p,0)` 后平均；excess width 用 `max(width-oracle_width,0)`。SV 的概率条件于模拟潜在波动状态，不冒充观察历史条件覆盖率。
- 两个预设引用组 Gaussian/t5、D128、A3 保存 seed4101 的已发出尺度，供额外控制器补充实验及抽查；参考组并非测试选优。该补充不能提供五种子稳健性结论。

本轮不依照测试结果选择网络、参数、校准设置或展示情景。独立测试仅用于此固定方案的评估；后续若据此设计方法，需要新的最终留出数据。
