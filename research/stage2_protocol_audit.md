# Stage 2 确认性模拟协议独立审查

日期：2026-10-11。审查对象为拟定协议，而非已运行结果。只涉及自行模拟数据；不使用微众数据或 HPC 凭据。不将诊断干预当新算法，不承诺一般覆盖或课程评分。

## 最重要的改进

1. 明确一个主指标和有限数量的主对比，不能把全部架构、阶段、分布、持续时间、三种损失及交叉分量都当独立确认性结论。
2. 所有 event-minus-no-change 使用相同绝对日期、同创新、同潜在波动轨迹；必须在路径层面先算配对差再汇总。
3. recovery64 是固定 64 步成本，不是完整恢复。滚动 W=128 与 context=64 的污染最迟在退出后 192 步完全移出；额外画到 256 步，并检查预测精确重合。
4. Student-t 创新必须方差标准化，oracle 用对应 t CDF/分位数。SV 的真实 latent scale 只能产生 oracle-state coverage，不能直接称可观测历史条件覆盖。
5. 128 条测试路径不能弥补只有 5 个训练种子。主置信区间若只重抽测试路径，结论须明确条件于这 5 个拟合模型；跨训练种子的 bootstrap 只作敏感性分析。

## 1. 冻结协议时需要写清的对象

建议采用相同训练/验证路径、目标时点和 context16/64 混合比例，分别训练 GRU 与因果 TCN，每种架构 5 个权重初始化/优化随机种子。同一 checkpoint 测试两种 context，避免独立训练导致的参数混杂。

共同训练数据若在所有种子中固定，则这 5 次重复只衡量初始化、mini-batch 顺序等优化随机性，**不涵盖重新采样训练集的不确定性**。记录数据生成种子与权重种子两张独立列表。early stopping 使用共同的验证目标与 context 等权损失；训练步数上限、patience、最小改进量、选择准则先冻结。若最优 checkpoint 仍在最后一个 epoch，不能声称训练已充分收敛，应执行预先定义的延长规则，而不是看测试效果决定。

TCN 实际 receptive field 必须至少覆盖 64 步，禁止未检查结构就将 context64 称长记忆。明确 dilation/kernel/层数、输出仅取最后因果时点、padding 与 mask；GRU 每个有限 context 重置 hidden state。若 GRU 流式状态不重置，64 步有限记忆界不再成立。dropout 等在推断时关闭。参数量和训练计算预算记录并尽量相近，但相近参数量不证明有效记忆相同。

测试 grid 的含义要唯一：D∈{1,5,32,128,256}，幅度 A∈{1.5,3}，确定尺度 Gaussian / unit-variance t5，以及 SV 背景。明确 SV 是仅 Gaussian 还是与两种创新分布都交叉，避免运行后再扩大检验族。训练/验证可见与不可见的 D、A、尾部分布分别列出。新的测试路径独立于 pilot、训练和验证；先冻结脚本/配置 hash，再生成最终测试。

## 2. 主指标、主假设和多重性

建议唯一主指标为**退出后固定 64 步的 event-minus-no-change 平均 interval score 交互**。90% 区间时，`IS = (U−L) + 20(L−y)1[y<L] + 20(y−U)1[y>U]`。负效应和零效应均保留；它同时惩罚过宽和漏覆盖，不需要另设事后覆盖筛选。

令 `M_event(s,i,c,w;g)` 表示训练种子 s、路径 i、情景 g、当前与归档都用 context c、校准窗口 w，在 `[onset+D, onset+D+64)` 内的平均 IS。控制 `M_control` 必须使用**同一绝对区间**。先定义

`ΔM(s,i,c,w;g) = M_event − M_control`，

再定义对角可部署配置的交互

`J(s,i;g) = [ΔM(64,128)−ΔM(64,32)] − [ΔM(16,128)−ΔM(16,32)]`。

它回答“长/短预测上下文是否改变校准窗口对事件残留成本的作用”，不是“较长上下文整体更好”。零均值点预测固定，oracle 只给评估器。

**推荐有限主检验：**基于独立 pilot 已提出的问题，预先指定 Gaussian、A=3、D=128 一个复验情景，对 GRU 的 J、TCN 的 J，以及 TCN−GRU 的 J 差异作三项方向中性的主对比。使用新测试轨迹与新充分训练 checkpoints；三项置信/检验结论作 Holm 或同步校正。选择复验情景受 pilot 启发是可接受的，应公开这一事实，不可假称未经探索选择。

其余 duration/amplitude/tail/SV grid 用于预先计划的机制边界分析。若要在这些单元上作确认性显著结论，另列完整检验族并用同轨迹 bootstrap 的 max-t 同时区间或 Holm 校正，不能挑显著单元。零结果并不证明没有交互；只有事先定义的实质效应阈值及落在该阈值范围内的不确定区间，才能讨论限定的实质近零结果。

若研究目标必须是整个 grid 的平均作用，也可把预先等权的 macro-J 作为主 estimand，GRU/TCN/差异仍只三项主对比。但**macro-J 近零可能只是不同情景正负抵消**，不能据此证伪所有机制或宣称不存在交互。不得看完 grid 后从单情景方案改成 macro 方案或反过来。

覆盖不足面积、额外宽度、进入期 IS、恢复192、各交叉分量、seed 方向一致性均为预注册次要诊断。不要分别挑“最优覆盖”和“最优宽度”。不同 DGP 如需宏平均，应使用预先固定的训练尺度常数标准化；禁止选择能让结果好看的测试事件尺度。固定 90% 为主，95% 若加入只能列稳健性检查。

## 3. event-minus-no-change 与 finite-memory 负控制

对每个路径生成一套创新 z、一套 SV 潜在创新 ξ；所有事件长度、幅度、context、window、训练种子与架构均复用相应基础路径。无事件控制为同一 z、同一 v，唯一差别是乘性 pulse。退出后 event 与 control 的观测完全一致，故恢复差衡量先前事件通过历史输入/校准状态留下的影响。

`onset=384` 必须仅供评估，算法不接收时钟/事件标签；训练事件时点随机化，所有方法在 onset 前已过共同 warm-up。检查首次事件预测区间在 event/control 上相同，前缀预测也应逐点相同。第一次真实尺度跳升前没有可观测证据，漏覆盖不能被解释成可因果避免的模型失败。

进入期 onset32 对 D=1/5 混合了事件和恢复，不能把它称所有情景的“事件期”；退出64 使用相同长度则可直接比较。对 D=256，exit=640，退出后 256 步终点896仍小于 T=1024，可以看充分恢复。

有限上下文、滚动分数和冻结权重下，令 exit 为第一个恢复基准尺度的时点：当前 context a 的尺度在 `t≥exit+a` 与控制相同；按历史 context b 归档的分数在 `t≥exit+b` 相同；window w 的阈值在 `t≥exit+b+w` 相同。因此半宽在

`t≥exit+max(a,b+w)`

必须与控制一致。a,b≤64、w≤128 时统一界为 exit+192。请用索引定义验证边界附近 ±1 的时点，并在该界后断言数值重合。它对随机 SV 也成立，只要潜在轨迹共享、pulse 不反馈改变 v。若不重合，先排查状态、padding、索引或数据路径；这不是新的长记忆现象。

ACI、PID 或其他持久状态控制器不受这个有限窗口界约束，不能将192步归零要求套到它们。未来引入在线权重更新也会改变此界。

## 4. Student-t oracle 与尺度定义

若 `Tν ~ Student-t(ν)`，令 `cν=sqrt((ν−2)/ν)`，`z=cν*Tν`，则 ν>2 时 `Var(z)=1`。t5 取 `c5=sqrt(3/5)`。令 `y=μ+σ*z`，此处 σ 是给定生成状态的标准差，不是标准 t 分布的 scale 参数。

中心 1−α oracle 区间半宽为

`h_oracle = σ*cν*t.ppf(1−α/2,ν)`。

对因果产生的任意 `[L,U]`，给定真实 σ、μ 的状态条件覆盖为

`t.cdf((U−μ)/(σ*cν),ν) − t.cdf((L−μ)/(σ*cν),ν)`。

零中心对称区间则为 `2*t.cdf(h/(σ*cν),ν)−1`。Gaussian 情景使用 norm CDF/ppf，不能把它复制给 t5。有限方差标准化后，90% t5 中央区间不一定比 Gaussian 更宽；“厚尾所以所有分位区间更宽”不是正确直觉。

检查生成器样本方差趋近1、oracle 状态覆盖等于0.9、oracle 宽度与 CDF反演一致。若模型在 t5 测试时仍采用 Gaussian NLL 训练，应称创新分布迁移/稳健性测试；oracle 分布不能因此也错用 Gaussian。

## 5. stochastic volatility 的条件信息集

明确模拟顺序，例如 `v_t = μ_v + φ(v_{t−1}−μ_v) + ηξ_t`，`ξ_t~N(0,1)`，`y_t = m_t*exp(v_t/2)*z_t`；m_t 为外加尺度 pulse。v 的递推不受 pulse/y 的反馈影响。初始化采用 stationary v 或充分 burn-in，不能所有路径从 v=0 开始却称 stationary。

φ=.95、η=.12 时 stationary `Var(v)=η²/(1−φ²)≈0.147692`。若 μ_v=0，`E[exp(v)]≈1.0766`，基础收益的无条件方差也约1.0766，而非1；这不错误，只须声明。若希望无条件方差为1，可设 `μ_v=−Var(v)/2`，并相应写出均值回复递推。unit-variance 创新与 unit-variance 收益不能混称。

给定真实 v_t 的 `σ_t=m_t*exp(v_t/2)` 可以代入上节 CDF，得到**oracle-state conditional coverage**。它条件于模型没有看到的 latent state。部署模型仅见 `H_{t−1}=σ(y_<t)`；正确的可观测历史条件覆盖需要

`E[ F_z((U_t−μ_t)/(m_t*exp(v_t/2))) − F_z((L_t−μ_t)/(m_t*exp(v_t/2))) | H_{t−1} ]`，

还涉及 v_t 在隐藏状态模型中的后验预测积分。若状态 pulse/onset 也是隐藏且随机，其不确定性也须进入该信息集。真实 v_t 的 CDF 不能代替这个积分。

本阶段建议不额外建立过滤器，直接把曲线准确标为 oracle-state coverage，并另报按独立路径平均的经验覆盖。对有因果区间的模型，状态条件 CDF 在重复模拟下可提供低噪声的总体覆盖诊断，但不能称该模型获得可观测历史条件覆盖保证。真正的 observer-history oracle 若未来加入，需要独立嵌套模拟/过滤方法，并说明有限 Monte Carlo 误差。

## 6. 只有5个训练种子时的不确定性

所有方法共享128条路径，seed×path 是 crossed design。保留 `J[s,i]`，不能当作640个独立样本。主路径不确定性可对 `J_bar[i]=mean_s J[s,i]` 进行配对路径 bootstrap；一次重抽的 path IDs 同时用于全部模型、情景、上下文和window，使事件控制及架构差异始终配对。此区间**条件于已经训练的5个模型集合**。

同时报告5个 seed 均值、范围/标准差与 leave-one-seed-out 均值。若重抽 seed 和 path，必须各自独立抽索引且保留整个交叉矩阵，不能每个seed另外抽一套独立路径后假称原设计。5个seed的 crossed percentile bootstrap 对训练分布尾部估计薄弱，只作敏感性分析，不能作为普遍训练鲁棒性的证明。

若目标是对任意重新训练的模型作推断，需要更多训练重复，可能还要重复训练数据抽样。只有5个配对训练重复时，严格两侧符号/配对随机化的最小可达到 p 值为 `2/2^5=0.0625`（还须满足相应对称性/随机化假设），所以不应利用128条路径制造跨重新训练层面的 p<0.05 故事。新增训练种子如要做，需预先规定数量或固定停止规则，不能逐次加到显著为止。

## 7. 交叉干预的解释

完整诊断 `current a × archive b × window w` 是2×2×2设计。a≠b虽可严格只用历史，但本阶段仅定位结构效应，不是新部署法。对角 a=b 才对应标准化分数与当前尺度来自同一 forecaster 的原配置。

两条合法分解路径给出的分量可以不同；报告参照条件与三阶交互，不宣称唯一归因。`log half = log current_scale + log archived_q` 是恒等式：固定 b 时 current×window 的 log-width 交互恒为零；不要对该结构零进行显著性检验并当作发现。IS 非线性，其 current×window 分量可非零，二者不矛盾。

预注册图和表的命名应使用“event-induced interaction”“oracle-state coverage”“fixed-horizon recovery cost”“diagnostic archive intervention”。禁止把不显著叫证明等效、把state-CDF叫一般条件覆盖、把某个seed/情景符号叫普适神经机制。确认性结论限于冻结模型、明确DGP、固定目标与检验范围。
