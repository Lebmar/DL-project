# 回来后先读这里：项目研究什么、做到哪里

日期：2026-10-11。项目已经完成两轮统一神经训练、配对模拟测试和独立重训重复。现在最重要的进展是一个能够解释、复现并接受失败结果的研究问题；还没有证明新算法优于已有方法，也不能保证 A+。

当前工作题目是 **Separating Neural Scale Response and Score Memory in Online Interval Calibration**，可以理解为“拆开神经波动预测与历史误差档案，研究它们怎样共同影响预测区间”。[工作报告 PDF](../output/pdf/working_report.pdf)已完成四页主体加一页参考文献，并逐页检查排版；它是供你评议的**审核草稿**，不是正式提交稿。[一页 proposal](../output/pdf/project_proposal.pdf)也已备好草稿，最终仍须你核对作者信息、理解内容并作决定。

## 这个 project 到底在研究什么

设想我们每天需要给下一次收益变化画一个上下区间。GRU 或 TCN 读取过去的收益，估计“下一步大概会波动多大”；校准器再根据过去的预测误差决定区间应该放大多少。模型在高波动冲击进入时扩张区间、冲击结束后收缩区间，但两个部分各自保留历史，因此可能协调，也可能抵消。

这里有两种不同的历史作用：

| 部分 | 平常语言 | 实验里怎样改变 |
| --- | --- | --- |
| 当前预测尺度 `s_t` | 神经模型此刻根据过去观测给出的波动幅度 | 同一个冻结模型分别读取过去16或64步 |
| 历史 normalized-score 档案 | 过去的实际波动，除以当时已经发出的预测尺度；保留模型过去误差的记录 | 历史分母分别来自16/64步预测，档案窗口保留32或128步 |

例如，过去真实变化为2、当时模型估计的尺度为1，档案存的是2；如果当时尺度为2，档案存的是1。历史尺度的响应不同，就会留下不同档案。今天的区间半宽是“今天的尺度 × 过去档案的高分位数”，因此今天预测相近，也不代表最终区间相近。

我们把**当前尺度**和**历史分母**独立交叉，再配上两种档案窗口，完整保留八种组合。通常方法使用同一个 context 产生当前尺度和历史档案；交叉组合让我们看清差异来自哪里。模型权重保持固定，预测只看过去观测；实际当前结果、冲击标签和模拟真实波动都不进入预测输入。

研究重点是这两个计算通道的组合，不是猜下一步涨跌。当前模型的中心固定为0，用来隔离区间宽度问题。金融应用提供动机，公开汇率已有可行性探索；主要机制证据来自受控模拟，尚未建立真实金融部署优势。项目没有使用微众比赛的受限数据。

## `J` 不是模型胜负分数

Interval score 同时处罚过宽的区间和区间外的实际结果，越小越好。`J` 则由多个 interval-score 差值组成：它问“把 context16 改成64的效果，会不会随着档案窗口32改成128而变化”，并再减去没有冲击、但基础噪声完全相同的配对路径上的变化。

所以 `J<0` 不能直接翻译成“长记忆有益”、`J>0` 不能翻译成“长记忆有害”。`J_GRU−J_TCN<0` 也不能直接翻译成 GRU 的绝对区间更好。最终区间是否更有效，应另外查看 interval score、coverage 和 width；单独提高 coverage，可能只是把区间放得更宽。

Current/archive 的分量可以反向抵消，总 `J` 很小不代表两个作用都很小。两种改变顺序都要保留；分量是明确的计算差分，不能说某个通道“解释了多少百分比的因果影响”。基础恒等式、有限遗忘界和评分曲率推导用于理解与检查，本身不被包装成原创定理。

## 实际完成的结果与失败边界

Stage 2 使用同一份训练/验证数据、五个初始化/采样 seeds、两架构，共10个冻结拟合；随后完成全部30个预定测试case。Stage 3 换成三份独立训练/验证数据，每份仍有五个配对 seeds和两架构，共30个新拟合，并用新的Gaussian/t5路径重复四个case。不是只挑几个最好结果。

下面是预定 Gaussian D128 A3 case 的主要 `GRU J−TCN J`；entry评分冲击进入后的前32步，recovery64评分冲击结束后的前64步。

| 主要 contrast | Stage 2 五对固定拟合均值 | Stage 3 三panel×五对固定拟合均值 | Stage 3 三个panel均值 |
| --- | ---: | ---: | --- |
| entry | −0.05287 | −0.19857 | −0.31008、−0.25474、−0.03089 |
| recovery64 | +0.03276 | +0.00695 | −0.01103、−0.01067、+0.04254 |

**Entry 的方向在三个新训练panel重复了，recovery 的正向差异没有稳定重复。**不能把 recovery 原结论保留下来，只展示它成功的那一组；重复失败就是当前研究边界。

在 Stage 3 Gaussian entry 的“3个训练panel × 两条分解路线”中：

- TCN current 分量跨五个seed的标准差比 GRU current 更大：**6/6** 个组合。
- TCN current 分量的标准差比它自己的 archive 分量更大：**4/6** 个组合。Panel1 的 archive 反而更大，不能说 current 永远主导。

两条路线使用相同模型、路径与格子，六个组合彼此相关，不是六次独立重复。标准差也不能转换成某通道贡献的方差百分比。完整数值和所有拟合见 [Stage 3 readout](stage3_results.md)。

验证集梯度、旧输入置换和人为 pulse 响应已完整计算。它们帮助理解模型依赖，但当前散点没有建立“pulse 诊断超出 NLL 的稳定预测能力”。我建议先理解现有结果，再决定是否值得另冻一轮新拟合holdout；具体取舍见 [预测验证设计审查](diagnostic_prediction_design_review.md)。

## 两种区间回答不同的问题

把保存好的神经模型固定，只重抽模拟路径，回答的是：“对这些已经训练好的模型，换一组冲击噪声，平均差异有多不确定？”这叫 fixed-fit paired-path interval。Stage 3 entry 的97.5%区间为 `[−0.24939,−0.14849]`，recovery64为 `[−0.00521,+0.01922]`。

再改变训练数据panel和初始化/采样seed，回答的是：“如果重新训练，方向还稳不稳？”Stage 3 的 crossed sensitivity ranges 为 entry `[−0.42548,+0.01792]`、recovery64 `[−0.05893,+0.06728]`，都包含0。三个训练panel和五个共享seed还少，因此只能谨慎使用这项敏感性检查。

这两个读数并不矛盾：一批固定模型在许多路径上的均值可以很明确，重新训练后却变动较大。不能把30个模型×128条路径当成3840个独立样本。同一个seed跨三个panel共享初始化/采样规则；两架构共用路径；不同duration还共用基础噪声。特别是D32/D128的前32步完全相同，其entry相同来自因果性，不是额外的鲁棒性证据。

| 50–60分钟 | 不看说明，完成下面五项自测；把评议记在本地笔记 | 判断当前叙事是否成立，再选下一步实验 |

五项自测，供你检验自己的理解：

1. 用一个数值例子解释，为什么同一个过去实际结果、不同当时预测尺度，会留下不同normalized score。
2. 解释为什么相同的今天尺度仍可能产生不同最终区间，以及为什么八格交叉比只看四个diagonal配置多提供信息。
3. 解释为什么 `J_GRU−J_TCN<0` 不能独自证明GRU更好；另外应检查哪些指标。
4. 说明 fixed-fit路径区间很窄、crossed敏感性却跨0为何可以同时成立；指出当前有哪些共享随机性。
5. 用两三句话分别写出一个当前支持的结论、一个没有稳定重复的结论、一个还不能声称的原创贡献。

下一步先由你评议研究问题、报告草稿和这些失败边界，然后再决定新增实验。不要为了继续运行而自动增加元模型、gating或校准修复；如果选新方法或预测验证，应先固定规则，再使用新的独立评估。
