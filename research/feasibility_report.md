# 第一阶段结论：可以继续，但 A+ 贡献尚未成立

核查与先导日期：2026-10-11。当前决定是保留金融预测区间方向，把问题收紧为：**神经预测器的尺度响应，会怎样改变在线校准在波动冲击进入、退出时的效果？**不预设长记忆更差，也不预设神经模型胜过统计模型。

## 已完成的实质工作

1. 对照九页课程 guideline，建立了要求映射；正式深度学习模型已从头训练，不只是跑统计校准。
2. 查阅原始论文与作者代码，排除了把窗口集成、重置、replay、神经残差控制器当作首次提出的方案。最接近的研究及未决全文核查见 [文献备忘录](literature_gap.md)。
3. 下载并固定 ECB 公开历史汇率，构建 USD/JPY/GBP/CHF 对 EUR 的下一可用公布日百分比对数收益率。完全不使用微众数据、派生特征或旧比赛结果。
4. 跑通手工摘要 MLP、真正的 GRU 配对模拟、三种子公开汇率 GRU、作者源码 SF-OGD/SAOCP，以及当前尺度与历史分母的交叉诊断。
5. 增加真实未来后缀干预、同前缀检查、预测存档复核、配对不确定性估计；独立审查没有发现测试未来信息泄漏。
6. 制作一页官方 NeurIPS preprint 格式英文 proposal 草稿，并视觉检查版面。

## 先导结果教会了我们什么

### 模拟：不能把一种模型的现象推广到全部神经网络

原 MLP 使用人工 EWMA 摘要作为输入，改变的是摘要时间尺度。持续升波动进入后前 32 步，扣除无事件同窗后的区间分数交互约 **+1.1769**。它只是该摘要模型与设定的结果，不能称神经内部记忆发现。

真正的 GRU 使用原始历史收益与逐点幅值特征，以同一训练权重处理 16/64 步上下文，交叉 32/128 步校准窗口。3 个训练种子、128 条共享测试路径的对应调整交互约 **−0.2045**，三种子均为负，探索性交叉 bootstrap 区间约 **[−0.2455, −0.1661]**。短暂 1 步冲击结果接近零，5 步冲击的效应很小。

两套 pilot 的训练设置、输入、上下文、事件起点和路径数不完全一致，因此这不是隔离“架构差异”的直接实验证据。它足以否定依据第一套结果预设普遍放大效应的写法。仅有 3 个训练种子也不能精确描述全部训练不确定性；所有种子的最佳验证轮次均在第 8 轮，尚未确认充分收敛。

交互定义为：

```text
[(long context, long calibration) − (long context, short calibration)]
− [(short context, long calibration) − (short context, short calibration)]
− the same interaction in the paired no-event trajectory/window
```

指标为区间分数时，正负号只描述差中之差，不等于某一个单独组合必然最好。短事件的“onset32”包含冲击后恢复，不能把它称为 32 步纯冲击期。

### 当前尺度与归档尺度：开始分离两条作用路径

普通上下文干预同时改变当前尺度和历史标准化分数的分母。额外交叉当前上下文 `a`、归档分母上下文 `b` 与校准窗口，保留完全相同 checkpoint 和测试路径，能够区分两部分。`a=b` 复现原 GRU 结果，最大误差约 `2.84e-14`。

持续升波动 onset32 的 −0.2045 可按指定干预路径精确分解为约 **−0.1444 的当前尺度×窗口项**和 **−0.0601 的归档尺度×窗口项**。后者的训练种子范围跨零，探索性区间也跨零，不能断言陈旧分母解释了全部效应。这种分解依赖固定哪条路径；应报告两个顺序及三阶交互，而不是唯一因果贡献百分比。

`log h_t = log s_t + log q_t` 是恒等式。固定归档尺度时，当前上下文×窗口的 log-width 交互等于零是构造结果，不是新经验发现。离开对角线的组合是机制诊断，不是具有额外覆盖保证的新算法。

128 步事件退出后的 64 步恢复窗中，原交互约 **−0.0571**，指定路径的当前尺度项约 **+0.0289**、归档项约 **−0.0860**。当前项的区间跨零，归档项三种子均负。这与进入期的分解不同，提示作用阶段需要分开研究；它仍只适用于这套已冻结模拟，不是一般神经机制的定论。

### 公开金融数据：目前没有清楚的神经优势

公开实验采用训练到 2018、验证 2019–2020、探索性评估 2021–2026-10-09。每个资产有 **1,479 个测试日期**；189,312 行原始预测只是方法、种子和资产的重复组合，不是独立样本数量。GRU 的 3 次训练使用验证损失选 checkpoint，校准器从验证期回放初始化后进入测试。

按资产训练期标准差归一化区间分数，先平均种子/资产，再对相同日期配对比较。20 日块 bootstrap 得到：

| 对比 | 平均差（越低越好） | 探索性 95% 区间 |
|---|---:|---:|
| GRU64 native − EWMA16 native | +0.0091 | [−0.0107, +0.0278] |
| GRU64 native − EWMA64 native | −0.0173 | [−0.0631, +0.0258] |
| GRU 上下文×校准窗口交互 | −0.0013 | [−0.0141, +0.0110] |

60 日块敏感性分析没有改变这项判断：当前数据未提供稳定优势或整体交互的证据。区间跨零不证明现象不存在。日期块法是探索性、条件于已拟合模型的分析，不能自动保证任意非平稳过程下置信区间有效。

SF-OGD/SAOCP 已用固定作者源码、同一 issued GRU 预测跑通。在本次默认设置下，区间分数高于 rolling128；这只是当前初始化和尺度启发式的结果，不是方法普遍更差的结论。2019 估计的 score scale 被部分测试分数超过，未截断测试分数，也没有套用要求硬上界的理论保证。详见 [强基线说明](strong_baseline_notes.md)。

## 与 A+ 的关系

这个问题仍符合“用实验对深度学习产生新理解”的课程方向，也可在个人项目的算力与时间内推进。**目前还不能称 A+ 级研究已经成立，更不能给出可靠的高概率承诺。**它的主要风险在于：机制不够神经特有、效应依赖设置、已有研究足够接近，以及公开数据上差异很弱。

冲击 A+ 需要额外得到至少一项有边界、可复现、近邻研究尚未解释的 insight，或者由该 insight 推出的必要方法改进，并用强基线、充分训练、独立测试与消融支持。单纯让模型更大、跑更多结果、换到金融数据，无法替代贡献。

下一阶段按 [实验决策关卡](next_experiments.md) 推进：先验证有效记忆，再用匹配设置比较第二个神经架构，完成强基线验证与独立稳健性 grid。没有证据前不把新适应模块写成已确定贡献。
