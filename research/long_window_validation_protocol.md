# 长窗口失败是否可重复：下一轮独立验证方案

日期：2026-10-18。**设计已冻结；2026-10-19执行器已实现并通过小样例检查，等待首次HPC运行。** 机器可读设定、全部新seed和来源哈希见[配置](../configs/long_window_validation_protocol.json)。实现完成后，必须先验证并提交源码，再首次生成这些新数据。

## 为什么先换测试路径

[本轮诊断](long_window_diagnosis.md)发现：总体近似在不同时间的误差相消，导致区段均值目标与逐端点目标的排名相反；同批创新交叉路径对照又使实际风险差缩小。三个相关读数的区间都包含0。现阶段应先确认它们是否跨独立测试样本重复，不能把共享一批路径的12个模型当作12次独立证据。

本轮不重新训练模型。这样新旧结果的差别主要反映测试创新变化，不同时混入训练数据和checkpoint变化。结论仍只针对这12个既有拟合；训练总体泛化需以后单独研究。

## 固定范围

| 项目 | 预设内容 |
|---|---|
| 神经模型 | 原3批训练数据中的12个GRU/TCN拟合，全部保留；context64 |
| 独立测试批次 | 16批，每批64条、长度640；每种创新分布总计1024条 |
| 情景 | Gaussian平稳、上涨1.5倍/2倍/3倍；单位方差t5上涨2倍 |
| 冲击 | t=256起，持续128步，其他时间真实尺度1 |
| 历史窗口 | 32、128；相邻秩概率混合，候选区间先评分 |
| 端点 | pre:192/208/224/240；entry:256/264/272/280；late:320/336/352/368；recovery:384/400/416/432 |
| 比较 | P总体混合、A原历史、D独立创新库、X同批交叉路径；D前后32次用于精度检查 |
| D | 每批64个独立创新重抽replicas；同批各模型/情景共享对应replica，跨批完全独立 |
| X | 每条anchor完整枚举同批其他63条创新路径，排除自身；不跨批混合 |
| 总网格 | 16批×12拟合×5情景×2窗口=1920组神经评价 |

模拟真实尺度、创新分布只用于离线机制诊断，不能输入神经模型或当作真实金融可用信息。当前创新解析积分，避免把当前观测噪声和历史校准误差混在一起。

## 三个主要假设

主要条件固定为Gaussian上涨2倍、context64、window128、entry四端点。每个模型/端点先平均所有16批×64路径；不同模型和不同端点保持明确的权重。

| 假设 | 统计量和方向 | 回答的问题 |
|---|---|---|
| H1：原失败重复 | G_phase = P的区段均值MAE − D的区段均值MAE，预测为负 | 原冻结目标下的失败是否跨新路径成立？ |
| H2：逐端点反向 | G_endpoint = P逐端点MAE − D逐端点MAE，预测为正 | 失败是否只针对时间平均后的风险，而逐端点D反而更准？ |
| H3：同批配对作用 | C = A−X的平均风险，预测为负 | 排除同批创新组成差异后，同路径配对是否仍有负风险差？ |

H1中先平均4端点再取绝对值；H2中先分别取4端点绝对值再平均。它们不是可互换指标。H3是定义好的离线交叉路径比较，不证明唯一神经通道的因果作用，也不代表可以部署X。

重抽整个独立测试批次，共12000次；所有模型、情景、窗口和时点共用批次索引，每次重算均值和绝对误差。对3个主要假设使用单项98.333%双侧百分位区间，名义Bonferroni家族水平95%。只有区间完整位于预设方向，且GRU、TCN各自点估计同向，才称该假设得到支持。H3另须同置信水平的16批均值Student-t区间也完整为负。

这仍是近似推断：只有16批，且绝对误差在零点附近不光滑，不能宣称精确有限样本保证。逐批、全部拟合/训练panel、16个留一批点估计均展示；不剔除不利批次，也不把模型数量乘入独立样本量。

## 数值精度和控制

对H1/H2分别检查D的Monte Carlo误差：各批独立重抽replica、批内保持模型配对，4000次；标准误须不超过效应绝对值10%，前后32次重抽的增益差不超过20%。若失败，标记精度不足，不追加replicas。H3的X完整枚举，不受D的重抽精度门槛影响。

必须通过的控制：

- 配对Gaussian情景在冲击首步的原单位半宽相同；此时过去数据尚无差异。
- 使用跨路径完全相同的确定性尺度轨迹（固定s=1和真尺度s=sigma两种诊断）时，每批平均A−X为零至浮点精度。A−D不要求恰为零。
- X有序矩阵的自身路径对角线重现A；当前及未来观测不影响当期已发布预测。
- 精确切线分解的凸余项非负；风险不低于真实条件分位数oracle。
- 训练来源、checkpoint、协议和评估源码哈希核对通过；训练器和旧结果只读。

主要误差统计之外，完整保留各端点、去掉首步后的3点、其他幅度/噪声/窗口/阶段、事件减配对平稳对照、风险切线与凸余项、均值乘积和协方差。均属预定次要边界检查，不另作未经调整的确认性显著结论。尤其不能看到H1不利后改用H2作为唯一主指标。

## 结果如何决定下一步

| 结果 | 后续决定 |
|---|---|
| H1未得到支持 | 不将原长窗口失败写成稳定规律；保留为有限样本与评价目标敏感现象，不开发针对它的网络修复 |
| H1负、H2正均支持 | 研究贡献聚焦风险评价目标与误差抵消；明确区段均值和逐时点两个目标 |
| H2也显示负向或不确定 | 不宣称逐时点改善；查清偏差、曲率和新批次变化，保留原预测失败 |
| H3未得到支持 | 不把原差异唯一归因于模型内生性；继续保留创新样本组成的解释 |
| H3支持 | 再推导能够事先预测配对差异的偏差/交叉项规则；仍需新条件验证与在线可得性审查 |
| Monte Carlo精度不足 | 对相关D比较标记不确定，不修改种子、追加数据或临时换指标 |

任一失败都完整保存。下一轮没有新增训练、金融数据下载或报告/PPT工作。首先实现并冻结评估器；该方案本身不创建后台任务或自动运行。
