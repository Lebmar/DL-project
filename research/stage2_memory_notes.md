# Stage 2：仅验证集的模型记忆依赖诊断

日期：2026-10-11。状态：已完成固定配置诊断。这里没有测试集结果、训练调参或 checkpoint 重选，也没有一般覆盖结论。

## 配置和可复现性

[诊断脚本](../scripts/stage2_memory_diagnostics.py) 在首次运行前单独提交，commit 为 `0ac4f6687031d66b484e88f6cbcdf07f8be165c7`。使用项目 `.venv/bin/python`，运行约1.04秒；训练源代码、冻结协议、validation 数组、保存的 target-pair 索引及全部 checkpoint 的哈希均通过检查。

全部10个模型共同使用已保存8192个 validation target pairs 的**前256个**，没有根据输出筛选样本。两架构各5个权重种子4101–4105，contexts为16和64。验证数组通过既有生成器重建并匹配训练 manifest 哈希；没有另采样验证数据。

旧历史干预在 context64 内把较早48个原始观测作为整块，在256个样本间进行固定置换；最近16个观测保持完全相同。置换 seed 为920110，整个置换共1个 fixed point，所有模型使用同一 donor 排列。置换可能打破局部波动状态的关联，并使用另一验证时点的历史块；它是**离线模型依赖诊断，不是在线可部署策略或真实世界因果干预**。

梯度按原始输入求 `|∂logσ_next/∂y_lag|`，lag1表示最后已观察时点。旧历史梯度占比定义为“先对256个样本平均绝对梯度，再计算lag17–64的总和占lag1–64总和比例”，并非逐样本份额的平均。若总梯度为零，份额记为NaN，避免误称模型仅依赖近期。当前10模型在这批输入上没有 clamp 命中或全零梯度样本。

## 描述性结果

下表先对每个模型的256个样本汇总，再报告5个权重种子的均值及范围；没有把1280个样本当作独立训练重复。

| 验证诊断 | GRU：5种子均值 [范围] | TCN：5种子均值 [范围] |
|---|---:|---:|
| lag17–64绝对梯度占比 | 0.1100 [0.0931, 0.1357] | 0.2649 [0.2321, 0.2999] |
| 置换较早48步后的平均 `|Δlogσ|` | 0.07032 [0.05779, 0.08539] | 0.09082 [0.07737, 0.12590] |
| context64与16的平均 `|Δlogσ|` | 0.04415 [0.03520, 0.05379] | 0.06088 [0.04552, 0.08998] |
| context64与16的平均 `|Δσ|` | 0.06834 [0.05958, 0.08022] | 0.09032 [0.06470, 0.13565] |

每个模型内，旧块置换 `|Δlogσ|` 的95%分位数范围为 GRU 0.1741–0.2466，TCN 0.2017–0.3236；这些是**各模型样本分位数的范围**，不是合并样本的单一95%分位数或置信区间。

所有5组配对权重种子中，TCN的旧输入梯度占比均高于GRU。但是置换平均变化及context变化并非每一组都由TCN更大，例如seed4101的置换变化TCN小于GRU。因此可保留的结论是：**这批训练模型在固定验证输入上呈现不同的局部敏感性分布，TCN的梯度敏感度更集中于旧输入；其他依赖指标存在种子差异。**

这不证明TCN拥有更好的有效记忆，也不证明其冲击退出恢复更慢或更快。梯度是局部依赖；较大非局部置换可以进入训练分布之外。两项诊断不能独立识别校准分数路径，也不能替代冻结测试中的事件配对比较。仅验证集诊断不用于修改已冻结主检验、模型或超参数。

## 产物与限制

[输出目录](../outputs/stage2_memory/) 包含：

- `selected_validation_pairs.csv`：256个保存pair索引、路径/目标时点和donor样本。
- `gradient_by_lag.csv`：10个模型×64个lag的平均原始输入绝对梯度。
- `model_memory_summary.csv`：每个模型的梯度占比、置换变化、context变化和clamp诊断。
- `target_diagnostics.csv`：10个模型×256个样本的context16/64尺度及置换输出。
- `validation_memory_diagnostics.png`：梯度曲线和逐seed描述性散点，已视觉检查。
- `manifest.json`：固定配置、代码commit、source/checkpoint/data哈希和输出哈希；状态`complete`，10模型。

验证pairs可能来自同一路径、重叠context甚至重复时点；它们不是256条独立序列。5个权重种子也来自同一固定训练数据。这里不提供iid置信区间，不把seed范围称统计显著性或对任意重训的保证。

诊断函数在运行前通过三个独立合成检查：仅最近16步的模型旧梯度份额/置换变化/context变化均为0；均匀依赖全部64步的模型旧梯度占比为48/64=0.75；全部饱和的模型份额为NaN。这些检查没有读取项目验证或测试数据。
