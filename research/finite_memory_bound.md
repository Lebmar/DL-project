# 有限上下文与滚动归档的遗忘界

这是本项目使用的直接推导与实现负控制，不宣称首次提出的理论。

考虑两个配对序列：事件与无事件。它们在事件退出时刻 `e` 起的所有观测相同，训练权重固定，预测尺度仅依赖最后 `L` 个观测；每个目标重新从固定初始状态编码该上下文。点预测固定为0。归档分数为 `r_i=|y_i|/s_i`，区间半宽 `h_t=s_t Q(r_[t-W:t])`。

当 `t >= e+L` 时，尺度输入全部处于退出之后，所以事件与无事件的 `s_t` 相同；同理，从 `i=e+L` 起两条归档分数相同。当 `t >= e+L+W`，分位数窗口也只包含相同分数，因此 `h_t` 完全相同。

更一般地，诊断组合当前尺度 context `L_a`、归档分母 context `L_b` 时，界为：

```text
t >= e + max(L_a, L_b + W)
```

本项目最大 context64、score window128，因此 rolling 方法最迟在退出192步后与配对无事件区间重合。原生无校准区间的界为64步。实施时按浮点容差检查；这是一项确定性输入依赖性质，不是覆盖保证或随机估计。

该推导要求**退出后观察真的相同**；现实市场在事件退出后的创新、潜在状态、模型重训和市场路径通常不满足这一反事实条件。持久隐藏状态、在线权重更新、全历史检索、ACI/SF-OGD/SAOCP 的持久控制状态都可能保留更早信息，因此不能直接套用上述界。不能把这个负控制当成现实市场必在192天恢复的预测。
